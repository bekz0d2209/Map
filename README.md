# FogMap — карта «туман войны»

Карта закрыта туманом и открывается клетками 2×2 м там, где ты прошёл.
- **Всё время**: общая карта всех мест, где ты был.
- **День**: маршрут за выбранную дату, километры и время в пути.
- Запись идёт в фоне (уведомление «FogMap записывает маршрут»).
- Все данные хранятся только на телефоне.

## Сборка APK
**GitHub:** залей эту папку в репозиторий. Workflow `.github/workflows/build.yml` сам соберёт APK и выложит его в Releases.
**Android Studio:** File → Open → эта папка → Build → Build APK(s).
