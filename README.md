# FogMap

Карта «туман войны»: открывается кругами радиусом 20 м там, где ты прошёл.

- **Карта**: туман, открытая площадь, сегодняшние км и время в пути.
- **Дни**: маршрут за любой день, км, время, новые места.
- **Места**: если стоишь на месте дольше 5 минут, приложение спрашивает «Где это мы?». Ответил один раз, и больше про это место не спрашивает.
- **Статистика** и **Настройки** (радиус, мягкость и плотность тумана, через сколько минут спрашивать, точность GPS, экспорт и импорт).

Работает всегда, в том числе после перезагрузки телефона. Все данные хранятся только на телефоне.

APK собирается автоматически при каждом push и появляется в **Releases**.
